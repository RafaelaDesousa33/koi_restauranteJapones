# Koi Restaurante Japonês

Projeto de um site moderno para um restaurante japonês, desenvolvido com foco em design, responsividade e experiência do usuário.

O site apresenta informações sobre o restaurante, cardápio, pratos em destaque e uma interface visual inspirada na cultura japonesa.

## Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript

## Objetivo

O projeto foi desenvolvido para praticar habilidades de desenvolvimento Front-End, criação de interfaces responsivas e construção de uma experiência visual moderna para um restaurante.
